# Handoff Tarea T02 - Cliente de YouTube Data API v3 y Sincronización de Canales

**Agente:** Gemini 3.8 Flash (T02 Implementation Agent)
**Estado:** COMPLETED
**Rama:** `feat/T01-common-module-setup`

## Resumen de cambios
- Se incorporó el módulo ejecutable `yt-api` al proyecto multi-módulo en el `pom.xml` raíz y en `yt-api/pom.xml`.
- Se configuraron las dependencias de Google API (`google-api-services-youtube:v3-rev20260902-2.0.0` y `google-auth-library-oauth2-http:1.30.1`), ShedLock (`shedlock-spring`, `shedlock-provider-jdbc-template`) y starters de Spring Boot 4.
- Se creó la clase principal `YtApiApplication` y se aisló la configuración JPA en `JpaConfig` para compatibilidad completa con pruebas slice `@WebMvcTest`.
- Se implementó `YoutubeConfig` soportando OAuth2 mediante `UserCredentials` (refresh token) o API Key.
- Se implementó `YoutubeApiClient` para interactuar con la YouTube Data API v3:
  - `fetchAllSubscribedChannels()`: maneja paginación con `subscriptions.list?mine=true` y enriquece en lotes de hasta 50 canales con `channels.list` para obtener `uploadsPlaylistId`.
  - `fetchChannelInfo()`: consulta directa para canales agregados manualmente.
- Se crearon los DTOs basados en Java 21 `record`: `CreateChannelRequest`, `UpdateChannelRequest`, `ChannelResponse`, `SyncResultResponse`.
- Se implementó `YoutubeSubscriptionSyncService` con lógica de upsert en `youtube_channel`, ejecución periódica con `@Scheduled` y candado ShedLock `@SchedulerLock(name = "youtube_subscription_sync")`.
- Se implementó `YoutubeChannelService` con operaciones de creación manual, paginación, actualización y sincronización bajo demanda.
- Se creó el filtro de autenticación `ApiKeyAuthFilter` para validar la cabecera `X-API-Key` en `/api/v1/youtube/**`.
- Se implementó `ChannelController` exponiendo los endpoints conforme al contrato C2:
  - `POST /api/v1/youtube/channels`
  - `GET /api/v1/youtube/channels`
  - `GET /api/v1/youtube/channels/{id}`
  - `PATCH /api/v1/youtube/channels/{id}`
  - `POST /api/v1/youtube/channels/sync`
- Se crearon pruebas unitarias (`YoutubeSubscriptionSyncServiceTest`) y pruebas slice MVC (`ChannelControllerTest`) con un total de 8 tests pasando al 100% (`BUILD SUCCESS`).

## Decisiones tomadas
- Se aisló `@EnableJpaRepositories` y `@EntityScan` en `JpaConfig` para evitar que los tests de capa web `@WebMvcTest` intenten instanciar la infraestructura JPA innecesariamente.
- En Spring Boot 4 se utilizó `spring-boot-starter-webmvc-test` con `org.springframework.boot.webmvc.test.autoconfigure.WebMvcTest` y `@MockitoBean`.
- Se estructuró `ApiKeyAuthFilter` para excluir automáticamente el callback público de WebSub (`/api/v1/youtube/websub/callback`) y Actuator.
